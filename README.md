 # Правила

В исходной строке и кофигурациях для замен запрещено использовать символы: ` `, `\`.

Символ `@` - считается служебным, используется для обозначения пустой строки. Пустая строка входит в любую строку и ее первым вхождением считается позиция непосредственно перед началом строки. Этот символ не может встречаться в исходной строке, а в конфигурациях для замен может быть только как отдельная строка. 

На вход запрещается подавать пустую строку. Поведение интерпретатора в таком случае неопределено. 

 Интерпретатор будет работать с тремя файлами: 
 
 `input` - строка входных данных
 
 `rules` - набор правил замены подстрок для Нормального Алгоритма Маркова
 
 `output` - строка, полученная после выполнения алгоритма
 
 В файле `rules` каждая инструкция подается c новой строки. Можно оставлять пустые строки. Инструкции бывают двух типов:
 
 * `A -> B` - замена первого вхождения `A` как подстроки на `B`.
 
 * `A ->. B` - замена первого вхождения `A` как подстроки на `B` и завершение программы.

`A` и `B` не должны содержать пробелов!

# Запуск интерпретатора

```./run.sh <path_to_input_file> <path_to_rules_file> ``` - Запуск интерпретатора на входной строке из файла `input` с правилами из файла `rules`.

Получившаяся строка-результат будет записана в файле `src/output.txt`.

# Описание примеров

* `example1` - Инвертирование. `0110101 -> 1001010`
* `example2` - Сортировка. `0110101 -> 0001111`
* `example3` - Удвоение. `0110101 -> 01101010110101`
